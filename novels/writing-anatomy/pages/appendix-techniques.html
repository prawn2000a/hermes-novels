技法庫 —— 爽文寫作可直接抄用嘅素材

全部素材來自一部系統流網文實測（2757 章 / 6,766,156 字），或按實測規律重寫嘅改良版。

1. 章尾鉤子句式庫（12 種）

參考作章尾鉤子率只有 11.5%，以下係改良版目標 ≥40%。

1.1 突變式 —— 外力打斷

就在這時候，門外傳來一聲輕響。 他正要開口，門外突然傳來一聲輕響。 話音未落，門被推開了。

1.2 懸念截斷式 —— 句子唔寫完

他這才發現，那張照片上的人—— 直到他看清那張照片上的人。 那個名字，他認識。

1.3 威脅式 —— 施壓者開口

你最好在天亮之前，給我一個答覆。 說完這句，他轉身就走，沒有回頭。

1.4 反轉預告式 —— 明知會出事

可惜，他算錯了一件事。 後來他才知道，這一開始就是個錯。 他這麼想著，卻不知道真正的局才剛剛開始。

1.5 選擇式 —— 兩難

兩個都要，一個都不能少。 留下，或者走。他必須現在就選。 只要他開口，這件事就再也回不了頭。

1.6 身份懸念式

這個人，他認識。 來人他見過——在通緝令上。

1.7 倒計時式

距離系統重置，還有十分鐘。 還有三天。三天之後，這裡什麼都不會剩下。

1.8 轉折語式 —— 動作突變

果然，X猛地轉頭，眼神直直釘在他身上。 然而就在這一刻——

1.9 資訊炸彈式 —— 一個數字鎮場

三百億。 兩千二百萬。 他欠的，不是錢。

1.10 主角自嘲式 —— 輕鬆收，讀者更擔心

完了。 他忽然覺得，這一趟是來對了。 這下有意思了。

1.11 配角失態式 —— 用旁人反應製造懸念

配角老臉一紅。 整個廳裡靜得能聽見燭火。 她的手，抖了一下。

1.12 靜默式 —— 空白製造壓力

沒有人說話。 整整十秒，沒有一個人出聲。

2. 震場反應池（60+ 種，分類）

參考作只用咗 12 種打盡 2757 章 —— 係弱點。新書必須用分類輪換。

2.1 震驚類（12）

所有人都是一愣。
所有人都很吃驚。
所有人都懵了。
所有人都震驚了。
所有人都驚呆了。
眾人面面相覷。
眾人皆驚。
全場震驚。
全場都驚呆了。
全場都懵了。
眾人一個個張大了嘴。
整個大廳瞬間安靜下來。

2.2 荒謬類（8）—— 適用於荒誕情節

眾人傻在原地。
所有人你看我我看你。
眾人如同見鬼一般。
這畫面，誰看了不懵？
眾人下巴都要掉了。
一群人集體失語。
眾人像被人掐住了脖子。
現場一片死寂。

2.3 忌妒類（8）

眾人眼裡閃過一絲嫉羨。
有人悄悄攥緊了拳頭。
那幾個女孩子的眼神都變了。
眾人看向他的目光變得複雜。
有人低頭，有人咬牙。
一股酸意在眾人心裡翻湧。
所有人的目光都黏在他身上。
羨慕，嫉妒，不甘。

2.4 憤怒類（8）

眾人臉都綠了。
所有人的火氣都上來了。
有人已經拔了刀。
眾人紛紛變臉。
一股怒意席捲全場。
所有人的拳頭都捏得咯咯作響。
群情激憤。
眾人怒目而視。

2.5 恐懼類（8）

眾人臉色煞白。
沒有人敢出聲。
所有人下意識退了一步。
恐懼在眾人臉上蔓延。
有人腿都軟了。
眾人看他的眼神變了。
眾人紛紛躲避他的目光。
殺氣，壓得眾人喘不過氣。

2.6 服氣類（8）

眾人服了。
有人直接抱拳。
所有人看他的眼神都變了。
眾人心服口服。
眾人紛紛低頭。
這一手，鎮住了所有人。
眾人不敢再說一個字。
有人倒吸一口涼氣，滿眼佩服。

2.7 尷尬類（6）

眾人尷尬地笑了笑。
氣氛一下子尷尬起來。
沒有人接話。
眾人面面相覷，誰也不開口。
空氣突然凝固。
有人乾咳兩聲。

2.8 興奮／轟動類（6）

全場轟動。
眾人沸騰了。
消息傳開，整個會場都炸了。
一片譁然。
眾人激動起來。
這消息，足以讓整個圈地震。

### 2.9 反差落點式 —— 爽點建立喺落差

眾人還在震驚，X已經坐下了。 掌聲還沒停，他已經往外走。 所有人還在算那道題，答案已經出來了。 眾人回過神時，事情已經辦完了。

⚠️ 呢類最重要。爽感 = **主體嘅從容** ÷ **旁觀者嘅震驚**。

## 3. 心聲（【】）寫法

**實測規格**：全書 1,950 段；407 章有；集中頭 400 章；系統提示只佔 6 段。

### 3.1 分類與配比（每章 ≤ 3 段）
| 類型 | 作用 | 佔比建議 | 範例 |
|---|---|---|---|
| **吐槽貶低** | 讀者共鳴 + 拉開主角同原著套路距離 | 50% | 【這種貨色也配當主角？】 |
| **算計盤算** | 讓讀者參與謀略 | 25% | 【得先讓他把話說完，再讓他說不出話。】 |
| **情緒爆發** |  comedic 落點 | 15% | 【靠！忘了今天要帶那個文件！】 |
| **系統提示** | 推進機制 | **≤10%** | 【叮。】—— 唔好寫大段台詞 |

### 3.2 硬規則
- 每段 **20–60 字**。超過 60 字就變散文，會拖慢節奏。
- 一章最多 **3 段**（參考作前 60 章平均 0.7 段／章，實務上 3 段已經係上限）。
- 系統提示**唔好寫成對話** —— 寫成感覺：「叮。」然後主角腦中浮現一行字，之後即刻轉入行動。
- 心聲**唔好解釋剛發生嘅事**（讀者自己睇到）。
- 心聲**唔好洩漏計劃**（會消解懸念）—— 只講態度同嘲諷，唔講步驟。

### 3.3 範例（改良版）

【大姐你快饒了我吧，跟你訂婚？我还想好好活几年呢！】 【身材是不错，脸蛋也极品，可惜了是个无脑大女主。】 【得先让他把话说完。说完，就该我说了。】 【好了，现在该算账了。】

## 4. 對話標記表

**實測**：9,142 種；主角「X道」佔壓倒性。

### 4.1 主角（用最簡潔）

X道：“…” ← 佔絕大多數 X点点头：“…” ← 動作嵌在標記裡 X笑了笑：“…” ← 參考作常用（86 次「笑着道」） X眯起眼睛：“…” ← 15 次，代表「起心計」


### 4.2 配角（用情緒變體）

X怒道：“…” X冷笑道：“…” X笑道：“…” X叹了口气：“…” X惊呆了：“…” X懵了：“…” X沉默了：“…” X点点头：“…” X不明白：“…” X倒吸一口凉气：“…” X瞪大了眼睛：“…” X皱眉：“…”


### 4.3 硬規則
- **動作永遠在說話之前**（`X怒道：“…”`），唔好 `“…” X說`。
- 同一章內同一標記**唔好超過 3 次**。參考作有 12 次「所有人都懵了」集中出現 —— 讀者會疲勞。
- 表情動作**一個動作一個動作寫**，唔好堆砌：「X震驚、愕然、傻眼、呆滯」。
- 對話標記後面**唔好加副詞**：「X震驚地說」「X開心地說」—— 會破壞節奏。

## 5. 稱謂表（身份錨點）

**實測**：每個角色固定一個稱謂。出現 2,000 次級別 = 核心角色。

| 稱謂 | 實測次數 | 功能 |
|---|---|---|
| 前輩 | 2,911 | 武俠資歷標記 |
| 暱稱 / 第四女主 | 2,529 / 1,469 | 暱稱 = 主角視角親密感 |
| 大哥 | 1,982 | 兄弟團核心 |
| 資歷稱謂 | 1,574 | 門派序列 |
| 家主 | 1,531 | 勢力層級 |
| 主人 | 1,309 | 主僕關係 |
| 小子 | 1,008 | 資歷壓制 |
| 老大 | 653 | 江湖稱呼 |
| 师弟 | 673 | 門派序列 |
| 殿下 | 485 | 皇族／高位 |
| 尊稱（暱稱） | 206 | 尊稱（暱稱） |

### 5.1 規則
- 同一角色**唔好混用多個稱謂**（除刻意對比）。
- **正式名 + 暱稱**對照使用係好招：正式名出現喺敘述，暱稱出現喺對話。用以表達「主角同佢熟」。
- 稱謂本身**承載關係資訊** —— 讀者見「尊稱（暱稱）」兩個字就知咩級數，唔使解釋。
- 新書：**每個角色寫死一個稱謂**，寫進角色卡。

## 6. 標點風格參數

| 標點 | 實測每萬字 | 用法 |
|---|---|---|
| ， | 502 | 基本 |
| 。 | 215 | 基本 |
| ！ | **187** | 情緒推動主力 |
| … | **119** | 停頓、話中有話、意味深長 |
| ？ | 104 | 對話密度指標 |
| — | 5.9 | **幾乎不用** |

**硬規則**：
- 驚嘆號密度高係爽文語氣核心，唔好克制。
- 省略號用嚟做「未說完的話」，一個章 1–3 個足夠。
- **唔好用破折號做插入語**（`他——其實不想`）。
- 半形標點零容忍。

## 7. 段落與排版

| 項目 | 實測值 |
|---|---|
| 平均段長 | 26.5 字（中位 22） |
| ≤10 字 | 17.3% |
| 11–20 字 | 29.3% |
| 21–40 字 | 36.3% |
| 41–80 字 | 14.6% |
| >80 字 | 2.5% |
| 每章段落數 | 平均 89.3 |

### 規則
- **一行一句**。唔好合併短句成段。
- **唔好寫章名**（參考作 2757 章只有 33 個標題行）。
- 最長段落**唔好超過 80 字**。
- 連續三段都係「動作描寫」= 悶，插入一句對話。
- 手機閱讀為主：每段 1–3 句最舒服。

## 8. 時間跳躍標記

**實測分佈**：每章 0 個（655 章）／1 個（799 章）／2 個（619 章）／3+（684 章）

**用法**：
- 標準標記：`第二天`、`翌日`、`三天後`、`一小時後`、`與此同時`、`同一時間`、`次日清晨`、`晚上`
- **每章 ≤1 個為主**（超過就散，讀者會斷線）。
- 跳躍之後**唔好再回頭補前段細節** —— 直接切入新狀態。
- 場景轉換嘅第一句要**立刻錨定地點**（例：「北方某國，北方某城。」「正廳。」「廢棄的老舊別墅地下室」）。
