## 三、硬性規則（寫作代理必須遵守）

### 3.1 語言
- **繁體中文書面語**，台灣讀者視角。
- **唔准粵語口語**入正文。
  - **絕對禁用詞表**：`嘅 咁 喺 唔 係 咗 啲 嗰 噉 嘢 冇 諗住 畀 呢度 嗮 咁樣 啱 攞 諗吓 呃 嘞 咯 嗱 細路女 行邊 點解 點樣 嚟 嚟緊 咁先 唔知 唔使 唔好 冇問題 乜 而家 依家 仲 擺烏龍 執生 一啲 啦 喇 喎 嚟咗 食咗 飲咗 行咗 傾咗 瞓咗`
  - **粵語句式禁用**：`食緊`（改「正在吃」）、`行邊`（改「要去哪裡」）、`食飯`（改「吃飯」）、`唔該`（改「謝謝」）、`咁大`（改「那麼大」）、`咁樣`（改「這樣」）、`仲有`（改「還有」）、`唔記得`（改「不記得」）、`好攰`（改「很累」）、`諗`（改「想」）、`睇`（改「看」）、`攞`（改「拿／取」）、`郁`（改「動／移動」）
  - **注意**：「食」「聽」「講」「說」「想」「看」係繁體書面語正當用詞，**唔好亂改**。
- 唔准簡體字（用「點」「劃」「斷」「岳」「學」「準」「橫」「籲」）。
- 唔准 Day X／第 X 日標記。
- 唔准正文引用章號（「上一章」咁樣）。
- 唔准佔位詞、亂碼、奇怪字符。
- 唔准連續破折號「——」連接句子。
- **全形標點**：逗號「，」冒號「：」分號「；」問號「？」驚嘆號「！」全部用全形。
- **唔准半形逗號 `,`**（機械生成指紋，最重要）。
- **唔准作者備註漏入正文**（「冰封名單」「場景人物」「正式登場留給章 XX」「不能寫進去」等內部筆記，一律唔准出現）。
- 「魔法」「兩位旅客」合計最多 2 次（最好 0 次）。
- 禁用：「續講」「即時」「我都想」「呢度」。

- **段落長度 70–110 字**（目標），單段不超過 140 字。
- **段落數 22–36 段**。
- 段落之間要有呼吸——唔准黏合成 150+ 字嘅長塊。

## 十一、已知陷阱（唔好再踩）

| 陷阱 | 說明 |
|---|---|
| **subagent 延遲覆寫** | subagent 可能喺主控注入 HTML 後又改 `_work/chNN_body.txt` → **注入後必須逐章 diff HTML vs `_work/chNN_body.txt`**，唔一致就重新注入 |
| **HTML 結構** | 唔好自行加 `<style>` 或 `<script>` 標籤；樣式要併入原有 `<style>` 內。已犯過一次：CSS 未包 `<style>` 導致 45 章頁面頂部出現 CSS 原始碼 |
| **注入 HTML 必驗** | 每次注入後，用 `html.parser` 解析確認 body 可見文字無片段外露（grep 唔夠——存在≠無外露） |
| **CSS 併入原 style** | 樣式文字會顯示在頁面頂部，一定要包 `<style>` |
| **章號引用誤判** | `<title>` 同 `<h1>` 內嘅「第 N 章」係正常嘅，只檢查 `<div class="chapter-body">` 內文 |
| **字數計法** | 用「漢字＋假名＋英數」，唔包含標點 |
| **「關係」誤判** | `verify-chapter.py` 已加 `(?<!關)係` 規則，唔好移除 |
| **API 429** | 一次最多派 3 個 subagent（`max_concurrent_children=3`），撞 429 就等下一輪 |
| **唔准 `git checkout` 還原** | 會丟失已 push 嘅章節改動 |
| **唔准郁章 11–50** | 已定稿重寫完成並通過驗證，只准做字數微調（章 15/22） |
