# 新書對照基準速查

寫新書時，用以下數值做對照：

章長 2,000–3,000 字（硬上限 5,000） 段落數／章 70–110 平均段長 ≤ 30 字 對話佔比 45–60% 心聲 ≤ 3 段／章，每段 20–60 字 反轉詞 每千字 6–7 個 時間跳躍 ≤ 1 個／章 章尾鉤子率 ≥ 40% ← 參考作 11.5%，必須改 震場反應池種類 ≥ 60 種 ← 參考作 12 種，必須改 對話標記種類 ≥ 50 種 ← 參考作 9,142 種 機制彈出間隔 ≤ 5 章 角色稱謂 每角色一個，出現 ≥2000 次 = 核心 低調:高調落差 1:6 ~ 1:5 標點 驚嘆號 ≥150/萬字，省略號 ≥100/萬字，破折號 <10/萬字
