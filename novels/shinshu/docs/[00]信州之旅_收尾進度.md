## 已知陷阱速查

| 陷阱 | 處理 |
|---|---|
| **subagent 延遲覆寫** | 注入 HTML 後必須逐章 diff `_work/chNN_body.txt` vs HTML（`check-injected-vs-source.py`） |
| 檢查腳本誤判外露 | `<style>` 內嘅 CSS 唔算外露；要用 `html.parser` 解析後取可見文字，唔係 grep |
| **`<div>` 配對錯誤** | 注入時用 depth 計數搵 chapter-body 對應嘅 `</div>`，唔好用 `find('</div>')`（會中 reader-note） |
| **full-gate 簡體字誤報** | SIMP 集合由「快乐」拆出「快」造成「快」誤判（快速／快門）→ 已移除 |
| **full-gate 粵語誤報** | 「喇叭」「自由啦」「仲見世通」被當粵語字；「關係」需 `(?<!關)係` 排除 |
| HTML 結構 | 樣式併入原 `<style>`，唔好新開 `<style>`／`<script>` 標籤 |
| API 429 | 一次最多派 3 個 subagent（`max_concurrent_children: 3`） |
| 字數計法 | 漢字＋假名＋英數，不含標點 |
| 「關係」誤判 | `verify-chapter.py` 已加 `(?<!關)係` 規則 |
| 章號引用誤判 | 只檢查 `<div class="chapter-body">` 內文，唔係 title/h1 |
