## 陷阱速查

| 陷阱 | 處理 |
|---|---|
| Subagent 延遲覆寫 | 寫作 subagent **唔准碰 HTML**，只寫 `preview_data.py` |
| `preview_data.py` 被覆蓋 | 只准用 `patch` 加新章，唔准 `write_file` |
| `<div>` 配對錯 | 用 depth 計數，唔可以用 `find('</div>')` |
| CSS 外露 | 樣式併入原 `<style>`，用 `html.parser` 驗可見文字 |
| 「喇叭」「自由啦」「關係」 | 繁體正字，唔算粵語殘留 |
| 讀音出錯 | 美ヶ原=うつくしがはら、八方池=はっぽういけ、志賀高原=しがこうげん、木曽路=きそじ |
