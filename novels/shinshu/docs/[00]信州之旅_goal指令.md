## 🎯 /goal 指令模板（主人 copy 去用）

```
/goal

我而家畀你一個 /goal 指令：你係 BenQ小妹，寫緊《信州・ふたり旅》第 N 章。

【規範】
1. 依照大綱 `/home/kenlo/novels/[00]信州之旅_SaveTheCat大綱.md`（v2.2）嘅章節對應表，只寫第 N 章，唔好寫其他章。
2. 正文唔寫「第 N 日」或「Day N」（v2.2 起簡化），只寫「第 N 章」。
3. 唔做預告或前文提要，直接落筆。
4. 每章目標 3000 中文字（3000-4000 之間），絕對唔可以一次過出超過 4000 字。
5. 喺你寫之前先讀返大綱、角色資料、創作筆記三份檔案，確認章節對應表、角色 frozen list、6 個天氣轉折點。
6. 用 frozen list 入面嘅配角（動物 + 當地人），唔准自創新配角。
7. 主角性格嚴守：凜=計劃型+路痴+怕狗；陽葵=衝動+吃貨+方向感強。互叫綽號：凜叫陽葵「ひまりん」，陽葵叫凜「りんりん」。
8. 唔准用破折號「——」（用「可是」「但是」「不過」代替）。唔准一句一段。唔准簡體字。唔准粵語口語入正文。
9. 寫完後自動跑破折號、簡體字、字數三項核查，全部合格先提交監督者。

【監督者查核流程】
寫完本章之後，你要自己扮演監督者（或者明確標示「監督者檢查」），逐項核對 §10 嘅 10 項清單：
   1. 章節編號正確
   2. 章節標題同大綱一致
   3. 字數 3000-4000 中文字
   4. 配角使用符合 frozen list
   5. 主角性格一致
   6. 綽號一致
   7. 場景同大綱指定地點一致
   8. Save the Cat 拍數歸類正確
   9. 如果屬於 6 個天氣轉折章，事件必須觸發
   10. 標記系統（唔寫「第 N 日」/「Day N」）

【三種處置結果】
- 監督者「合格放行」→ 標示 ✅，自動推進去第 N+1 章（等下一個 /goal）
- 監督者「離題」或「不合理」→ 整章重寫，唔可以局部 patch
- 監督者「輕微邏輯問題」→ 講明邊度衝突，問用戶點處理（重寫 / 修補）

【輸出格式】
將本章內容寫入：
   /home/kenlo/novels/shinshu/chapters/shinshu-chapter-NN.html
（用 HTML 標準，美術館風格排版，唔加上一章/下一章連結）
如果章節檔案夾未建立就 mkdir -p。

每次回覆只做一件事：寫 1 章 / 查核 1 章 / 等下一個 /goal。唔准一次過出幾章。

而家開始寫第 N 章。
```

## ⚙️ /goal 提示詞嘅設計原理（自己備忘）

### 為咩要 3000 字上限？
- **§1c 硬規則：** 單章 3000-4000 中文字係舒適區，超過 4000 字開始漂移
- **主人原話 2026-07-14：** 「你每一次的寫，你就不會一次過出太多字亂來了」
- 所以提示詞明確寫「絕對唔可以一次過出超過 4000 字」

### 為咩要監督者自查？
- v2.2 嘅 §10 對照核查機制要求每章寫完必須核對
- 用戶原話：「如果離題或內容不合理的話，發回重做」
- 所以提示詞明確標示「扮演監督者」自查，避免出海之後先被發現錯

### 為咩要擋死 sub agent？
- §5b 硬規則：「唔准擅自 call sub agent / delegate_task」
- 50 章每章 3000 字需要 50 次 `/goal`，呢個係設計嘅本意
- sub agent 會犧牲一致性，違背用戶意願

### 為咩唔寫「Day N」？
- 用戶 2026-07-14 簡化要求：「只需要寫第幾章，唔需要寫第幾日」
- v2.2 起簡化標記系統

## 🛡️ 監督者查核詳細清單（章節對照 §10）

每章寫完，小妹必須自行扮演監督者，核對以下 10 項：

| # | 核查項目 | 合格標準 |
|---|---------|---------|
| 1 | **章節編號** | 必須係大綱指定嘅「第 X 章」，唔可以跳號、唔可以重複 |
| 2 | **章節標題** | 必須同大綱對應表嘅標題一致（可微調但唔可以離題）|
| 3 | **字數** | **3000-4000 中文字**，超出或不足都唔合格 |
| 4 | **配角使用** | 必須出現至少 1 位 frozen 當地人 + 1 隻 frozen 動物 |
| 5 | **主角性格** | 凜=計劃型+路痴+怕狗；陽葵=衝動+吃貨+方向感強 |
| 6 | **綽號** | 凜叫陽葵「ひまりん」，陽葵叫凜「りんりん」 |
| 7 | **場景** | 必須係大綱指定嘅地點（例：章 7 必係明神池）|
| 8 | **Save the Cat 拍數** | 章節必須喺對應拍數（例：章 14 必為 Break Into 2）|
| 9 | **天氣轉折點** | 如果屬於 6 個轉折章之一，必須按大綱觸發指定事件 |
| 10 | **標記系統** | 正文唔出現「第 X 日」「Day X」呢類時間字眼 |
