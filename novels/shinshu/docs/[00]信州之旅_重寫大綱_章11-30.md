## 批次 1：章 11–16（定稿）

### 整體弧線設計

這 6 章係全書「Debate」段嘅中段，核心係**凜第一次主動提出一個超出計畫嘅想法**，並且被陽葵接受。

| 章 | 拍數 | 情緒位置 | 主題 |
|---|---|---|---|
| 11 | Debate | 溫暖 | 「記錄」本身可以成為目的 |
| 12 | Debate | 歡樂 | 意外的笑容（阿栗噴嚏） |
| 13 | Debate | 柔軟 | 陽葵的成年禮秘密 → 旅程意義被重新定義 |
| 14 | Break Into 2 | 崩裂 | 大吵（暴雨滯留 + 行程失控） |
| 15 | B Story | 和解 | 霧中行車：兩人第一次主動配合改變 |
| 16 | B Story | 沉澱 | 白樺湖清晨：關係被命名為「未定義但存在」 |

**關鍵設計原則（寫作代理必須遵守）**

1. **唔准用「兩位旅客」「魔法」呢類標籤式名詞**。原本每章重複 10–38 次，重寫後最多 2 次，且要自然。
2. **唔准用「續講」「我即刻」「我都想」**（粵語／機器口吻）。
3. **唔准重複問「我們會點」**。原本章 13、14、16 問咗三次同樣問題，現在只保留章 13 一次，章 16 改成具體的「十年後」問題。
4. **每章必有「具體感官細節」**（至少 3 個感官），唔准用抽象形容詞堆砌。
5. **每章必有 1 個「具體物件」貫穿**（呼應四件核心物品的其中一件）。
6. **段落長度 80–150 字**，段落之間要呼吸。
7. **每章末要有餘韻或鉤子**，唔可以用總結句收尾。

### 章 11 ｜ 木曾路・早苗女士的味噌

| 項目 | 內容 |
|---|---|
| **拍數** | Debate |
| **起點 → 終點** | 木曾奈良井宿・井筒旅館 → 木曾路・早苗女士味噌店 → 同宿井筒旅館 |
| **時段** | 清晨五點半 → 晚上 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 奈良井宿（宿場町街景）、早苗女士的味噌店（7 種味噌試食） |
| **配角** | 早苗女士（frozen，當地人）、中井先生（旅館老闆） |
| **核心物件** | 凜的旅行筆記本＋折疊地圖（本卷唯一一次主動拿出筆記本記錄） |

**情節節點**
1. 清晨五點半，凜醒得比全村早。窗外是奈良井宿的石板路與黑牆土倉，天還沒亮。
2. 旅館早餐。陽葵起得晚，凜一個人吃。餐桌上她已經在筆記本寫下今天的「三個想問的問題」。
3. 早苗女士的味噌店：開門第一件事就是搬味噌桶。她認出兩人是昨天的客人，開心到不行。
4. **試食場景**（本章重點，要寫得慢、寫得細）：七種味噌依次上桌——信州米味噌、赤味噌、白味噌、豆味噌、添味噌（米糠）、味噌玉（okratto 風）、最後一款她自己發明的。
   - 每款只寫**一個**具體感官（鹹度／甜度／質地／香氣），唔好逐款寫足。
   - 早苗女士說明「木曾的水硬，所以味噌鹹一些、發酵慢一些」。
   - 早苗女士談家族：1912 年祖父開始、母親改良成七款、她接下來要傳給女兒。
5. **情緒轉折**：凜發現自己買的量比預算多——她沒有停下來糾正自己，而是讓收銀機算完。**這是凜「計畫依賴」第一次鬆動的伏筆**。
6. 陽葵一口氣買了兩罐，因為「我要帶回去給媽媽，媽媽一定會喜歡」。
7. 回程路上，陽葵問：「你今天為什麼買了那麼多？」凜答不上來。她第一次對「計畫」這個詞產生疑問。

**情緒弧**：日常 → 溫暖（早苗的家族史）→ 微微不安（超預算）→ 餘韻（凜第一次對計畫產生動搖）

**要刪除的舊稿特徵**：整段「七種味噌逐一介紹」的清單式寫法 → 改成「只細寫兩款，其餘帶過」

**章末鉤子**：凜在筆記本寫下今天的日期，然後在下面寫了一句不是記錄的話：「如果有一天我不寫了，她們會怎樣？」

### 章 12 ｜ 木曾馬牧場・阿栗打噴嚏

| 項目 | 內容 |
|---|---|
| **拍數** | Debate |
| **起點 → 終點** | 井筒旅館 → 木曾馬牧場 → 井筒旅館 |
| **時段** | 早上七點半 → 下午四點半 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 木曾馬牧場（海拔 800 公尺）、馬廄、放牧觀察區、堆肥區 |
| **配角** | 木曾孝之（牧場職員，**場景人物，不命名為 frozen 角色**）、阿栗（frozen，木曾馬） |
| **核心物件** | 陽葵的公路歌單 USB（插入播放） |

**情節節點**
1. 早上出發，國道 19 號南下轉山路。陽葵插上 USB 播 Aimer，凜在副駕整理地圖（兩人第一次分工明確）。
2. 到達牧場，阿栗在馬廄最裡面。**重點場景：阿栗的噴嚏。**
   - 第一次：對著陽葵噴，噴到滿臉草屑。陽葵大笑。
   - 第二次：對著凜，風吹到臉上但沒有噴到。凜嚇了一跳。
   - 木曾先生解釋：馬用噴嚏表達「我注意到你」。
3. **凜與馬的關鍵**：凜伸手，動作很慢。阿栗沒有退開。
4. 放牧觀察區的木製平台。陽葵看著山谷裡喝水的馬群，說了一句：「她們好自由。」
5. **堆肥場景**（呼應主題）：馬糞 → 堆肥 → 附近的豆田 → 早苗女士的味噌。凜在這裡第一次看見「東西是有來源的」。
6. 午餐：牧場餐廳的自助餐、木曾野菜與蘋果。
7. 回程路上陽葵講不停阿栗。凜想起旅行筆記本第一頁寫的那句話。

**情緒弧**：期待 → 爆笑（噴嚏）→ 溫柔（凜摸馬）→ 沉靜（堆肥的因果）→ 餘韻

**要刪除的舊稿特徵**：「阿栗的祝福噴嚏」三段式解說（第一個=問候、第二個=接受、第三個=鍾意）→ 太機械，改成木曾先生用一句話帶過

**章末鉤子**：陽葵問凜今天最深刻的是什麼。凜答：「阿栗的噴嚏是她的語言。」但她真正想寫在筆記本上的是另一句：「世界是連著的。」

### 章 13 ｜ 白樺湖・陽葵的成年禮

| 項目 | 內容 |
|---|---|
| **拍數** | Debate |
| **起點 → 終點** | 奈良井宿 → ビーナスライン（美ヶ原道路）→ 白樺湖 → 美ヶ原「王ヶ頭ホテル」 |
| **時段** | 早上 → 傍晚 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | ビーナスライン、白樺湖（租小船）、白樺湖古松 |
| **配角** | 無 frozen 配角（兩人獨處章） |
| **核心物件** | 凜的筆記本（記下陽葵的秘密）＋陽葵預先寫好的一張紙條 |

**情節節點**
1. 開車上ビーナスライン，海拔從 800 升到 2000，氣溫下降，陽葵開暖氣。
2. 白樺湖午餐（便利店飯糰與罐裝咖啡）。**重點對話一：互補**。
   - 陽葵問「我們為什麼這麼合拍」，凜答「因為我們互補。你帶我出去玩，我幫你安排。」
   - 陽葵追問「三十天之後，我們會怎樣」。
3. **重點對話二：成年禮**（本章核心）
   - 陽葵說出家族傳統：每年夏天，家族最長的孩子要做一件「成人的事」。
   - 父親那年的事：幫家裡建一間木造房。母親那年的事：替一位婆婆照顧孫子一個月。
   - **今年輪到她：用三十天，開家裡的車，去沒去過的地方，帶一個好朋友。**
   - 凜的反應：震驚、然後眼眶熱。她終於明白陽葵不是「任性的十八歲」，而是一個「正在替自己策劃成年禮的人」。
4. 白樺湖租小船。陽葵在船頭，凜在船尾划槳。**山的輪廓像一個綠色的心。**
5. **島上老松**：陽葵用鉛筆在樹根寫下「りんりん + ひまりん，公路之始」，並貼上一張預先寫好的紙條：「我希望每年都會和りんりん回到這裡，做同一對公路旅人。」
   - 凜注意到：陽葵說「這就是我計畫好的」。這句話同時刺中凜——陽葵也有計畫，只是計畫的是「兩個人」。
6. 傍晚到王ヶ頭ホテル。窗外雲海。

**情緒弧**：開闊（公路）→ 溫柔（互補）→ 震撼（成年禮）→ 甜蜜（老松）→ 一絲被排除的刺（她已經計畫好了）

**章末鉤子**：凜在房間寫下「白樺湖。成年禮。我是她選的人。」然後停筆很久，最後加了一句：「這代表什麼？」

**注意**：本卷**唯一一次**出現「我們會怎樣」類問題。不要重複。

### 章 14 ｜ 美ヶ原暴雨・第一次大吵

| 項目 | 內容 |
|---|---|
| **拍數** | Break Into 2 |
| **起點 → 終點** | 王ヶ頭ホテル → 美ヶ原自然保護中心 → 山羊咖啡店 → 步道 → 同一間旅館（**不移動**） |
| **時段** | 清晨六點 → 深夜 |
| **字數目標** | 2100（1850–2500，本卷略長因為含爭吵） |
| **必到景點** | 美ヶ原自然保護中心、山羊咖啡店、王ヶ鼻展望點（2008 公尺） |
| **配角** | 団子（frozen，山羊）、山下先生（接駁車司機，**場景人物**） |
| **核心物件** | 凜的折疊地圖＋手機雷達圖（她的計畫工具）＋暈車藥 |

**情節節點**
1. 清晨六點，凜先醒。雷達圖顯示紅色雨雲正從南邊推進。她起床查資料、做決定——**不要寫成「她有預感」這種神秘化，要寫成她做了什麼具體動作**。
2. 早餐。陽葵起得慢。凜告訴她天氣要轉差。
3. 搭接駁車去自然保護中心。車上有其他遊客（名古屋中學生、老年夫妻），司機山下先生用擴音器提醒。
4. **山羊咖啡店・団子場景**（輕鬆段落要先放，讓後面的爆發有對比）
   - 陽葵蹲在玻璃窗外看山羊。店員說牠叫団子，7 歲，是店長。
   - 団子用角頂陽葵的手，要求多摸。
   - 凜餵牠米餅，団子舔走，用頭頂她一下。
5. **爆發點**：十點半出發走王ヶ鼻步道。雨越下越大。
   - 凜堅持要走到頂點（因為計畫表上寫了）。
   - 陽葵說「回頭吧，天太危險了」。
   - **凜的恐懼爆發**：她不是怕雨，是怕「失控」。她說出「如果我們在這裡出事了怎麼辦」——這句話戳中陽葵。陽葵說「你又在寫計畫了」。
   - 真正的爭吵內容：凜怪陽葵早上起不來耽誤了時間；陽葵說「你根本不是擔心我，是擔心你的表不對」。
6. 兩人分開。凜獨自在保護中心躲雨，對著玻璃看外面的雨。**這裡要寫她的內心轉折**：她翻開筆記本，發現自己連這種天氣都沒寫進風險欄。
7. 傍晚兩人各自回房。凜寫了一張紙條塞在門縫下（「雨停之後再說」之類）。陽葵沒有回。
8. 深夜。凜聽到陽葵房間有聲音（其實是陽葵在哭，或者只是翻箱倒櫃找雨具）。**兩人都沒有睡。**

**情緒弧**：不安 → 輕快（団子）→ 壓迫（步道）→ 爆發（大吵）→ 各自冷靜 → 懸而未決（門縫的紙條）

**章末鉤子**：門縫下的紙條被陽葵看見了，但沒有回應。凜在黑暗裡數著時間。

**注意**：唔准用破折號長篇連接（舊稿有「我們的關係 — — 我不知道」呢類）。改用停頓或句號。

### 章 16 ｜ 白樺湖清晨・命名為「未定義但存在」

| 項目 | 內容 |
|---|---|
| **拍數** | B Story |
| **起點 → 終點** | 白樺湖畔旅宿 → 白樺湖 → 別所溫泉旅館 |
| **時段** | 清晨 → 深夜 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 白樺湖（清晨）、湖畔咖啡店、別所公園、大湯（600 年歷史公共溫泉） |
| **配角** | 春枝婆婆（frozen，當地人） |
| **核心物件** | 陽葵的公路歌單 USB（Aimer，音量很小）＋凜的筆記本 |

**情節節點**
1. 清晨的白樺湖。只有兩個人，鳥聲清晰，湖面像鏡子。
2. 陽葵伸手扶凜下濕滑的碼頭。凜握住她的手。
3. **重點對話（本章核心）**：陽葵問「你覺得我們將來會怎樣」。
   - 凜答「我們會是一生的好朋友」。
   - 陽葵問「有沒有可能超越好朋友」。
   - 凜答「我想，要等我們都準備好去承認。承認我們之間，可能有一種比好朋友更深的東西。」
   - 兩人同意：**現在不定義，但要知道有東西存在。**
4. 湖畔咖啡店早餐（和式早餐）。
5. 抵達別所。春枝婆婆在旅館接待。（**移除作者備註括號**）
6. 別所公園散步，池塘錦鯉。

**情節節點**
1. 清晨。凜從地震的記憶裡醒來，記憶被睡眠沖淡。
2. 退房。旅館老闆娘送善光寺味噌。
3. 國道 18 號往北，約半小時車程到飯綱。陽葵播《まちぶせ》。
4. 飯綱高原入口的木牌。海拔 1000 公尺，空氣清涼。
5. **天鵝湖**：
   - 湖水清見底，水底石子與青苔把水染成翠綠。
   - 白天鵝在岸邊草地吃草。
   - **天鵝的動作很慢**（呼應章 30 官方定位）。
6. **陽葵看天鵝的眼神是羨慕**（舊稿有，保留）：
   - 陽葵說：「牠們好像不用趕路。」
   - 凜答：「牠們只是不用知道要去哪裡。」——**這句要保留，因為它是凜的覺醒。**
7. 午餐（高原定食）。
8. 2 公里環湖散步道 → 飯綱展望台。
9. **鳳凰盒的處理（必須符合硬設定）**：
   - 陽葵把鳳凰盒放在長凳上，鳳凰面朝天鵝湖。
   - **寫法**：月光或陽光下，木紋的深淺看得很清楚，翅膀上那一點金色在暗處也看得出。**唔可以寫「發亮」「閃閃」「如真的鳳凰」。**
   - 凜在筆記本寫：「飯綱高原。天鵝湖。散步道。展望台。星空。鳳凰盒。」
10. 夜晚露天風呂看星空（銀河、北斗七星、織女星牛郎星）。
