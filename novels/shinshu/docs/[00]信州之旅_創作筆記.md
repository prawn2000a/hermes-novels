## 🚨 寫作時必須遵守嘅硬規則

### 1. 章數 ≠ 日數嘅標記系統（§1b）
- ✅ 章節編號永遠用「**章 X**」
- ✅ 對應 Day 用「**Day X**」獨立顯示
- ❌ **絕對唔准混用「Day X」同「章 X」寫劇情**
- ❌ 寫「Day 45」會被即刻指出矛盾（總共只有 30 日）

### 2. 配角 frozen list 硬規則（§5c）
- ✅ 動物配角只能從呢 7 個入面揀：**豆豆 / 小白 / 小雪 / 団子 / 阿栗 / 小黑 / 閃電**
- ✅ 當地人配角只能從呢 9 個入面揀：**山下先生 / 田村伯伯 / 內田伯伯 / 早苗女士 / 春枝婆婆 / 健治先生 / 千世婆婆 / OL 三人組 / 田中一家**
- ❌ **唔准自創新動物 / 新當地人**
- ❌ 唔准兩位主角喺度自言自語，每章必須有「人氣元素」（人+動物+環境）

### 3. 寫作風格硬規則（§3）
- ❌ 破折號「——」連接句子（拆成兩句，用「可是」「但是」連接）
- ❌ 一句一段（每段至少 2-3 句）
- ❌ 使用 ◆ ◇ ═ 分隔線
- ❌ 過度感嘆號
- ❌ 粵語口語入正文
- ❌ 簡體字

### 4. 寫作流程硬規則（§5b）
- ✅ 用戶發 `/goal` → 小妹**自己親自**寫 1 章（3000-4000 字）
- ✅ 寫完自動跑破折號檢查（必須為 0）
- ✅ 寫完自動跑簡體字抽查
- ✅ 寫完主動提交審查，唔好沉默等指令
- ❌ **唔准擅自 call sub agent / delegate_task**
- ❌ 唔准未經用戶批准就 sub-agent 化某啲章節

## 🔍 邏輯核查清單（每次寫完一章都跑）

### 破折號檢查
```bash
grep -o '—' shinshu-chapter-XX.html | wc -l    # 必須為 0
```

### 簡體字抽查
```bash
grep -E '[的发展我们的你们的他们的这个那个]' shinshu-chapter-XX.html | head
```
常見簡體字黑名單：
- 的→的、發→发、我們→我们、這個→这个
- 開→开、長→长、東→东、車→车、語→语
- 風→风、見→见、時→时、學→学、親→亲

### 章節一致性檢查
- [ ] 章節編號同大綱對應表一致
- [ ] 對應 Day 唔超過 Day 30
- [ ] 動物配角名稱同 frozen list 一致
- [ ] 當地人配角名稱同 frozen list 一致
- [ ] 凜/陽葵性格設定一致（凜=計劃型+路痴，陽葵=衝動+方向感強）
- [ ] 兩人互叫綽號正確（凜叫陽葵「ひまりん」，陽葵叫凜「りんりん」）
- [ ] 唔准出現「Day 31」或之後嘅 Day
- [ ] 唔准出現早坂澪（v1.0 主角，已廢除）
