## 3. 「本章預告」寫作規格

### 3.1 固定格式（4 句，約 90–115 字）

```
第 1 句：自介     「我是桐野凜。」（第一次出現時用「大家好，我是桐野凜。」）
第 2 句：今日去邊  具體地點 + 一兩個感官細節
第 3 句：埋一點伏筆／情緒  唔好講死結果
第 4 句：期待收尾  「不知道會遇到什麼奇遇呢？真的很期待。」（可按章節情緒變奏）
```

### 3.2 語氣隨感情線演變（**核心要求**）

**語氣唔可以 47 章都用同一個模**。要跟住每章嘅情緒弧調整：

| 章節階段 | 預告語氣 | 範例句式 |
|---|---|---|
| **Setup（04–07）** | 好奇、拘謹、略帶距離 | 「我只站在原地數時間。」「又有點害怕。」 |
| **Catalyst（08）** | 第一次真正地疑惑 | 「我問了一個連自己都沒預期的問題。」 |
| **Debate（09–13）** | 內心掙扎、被動搖 | 「我開始覺得，我寫的那張表，可能有一點問題。」 |
| **Break Into 2（14）** | 難受、委屈 | 「那天我們吵得很兇。我不記得是為了什麼。」 |
| **B Story（15–19）** | 慢慢鬆開、開始主動 | 「這一次，我想自己決定。」 |
| **Fun & Games（20–28）** | 明亮、放心、有期待 | 「今天很開心，我差點忘記帶表。」 |
| **Midpoint（29）** | 心跳、被擊中 | 「有一瞬間，我以為整座寺都在晃。實際上不是。」 |
| **Bad Guys（30–36）** | 不安、裂縫 | 「有什麼東西開始不對了。」 |
| **All Is Lost（37）** | 痛、硬撐 | 「那天晚上，我把想說的話全部說了。」 |
| **Dark Night（38–42）** | 空、累 | 「很長的一段路，我們都沒有說話。」 |
| **Break Into 3（43）** | 脆弱、坦白 | 「我說出了這趟旅行一直不願意說的話。」 |
| **Finale（44–49）** | 安定、餘韻 | 「我很久沒有這樣安靜地坐著了。」 |
| **Final Image（50）** | 回家、餘韻、開放 | 「三十天結束了。但好像才剛剛開始。」 |

**規則：**
- 語氣要反映**當刻凜同陽葵嘅關係狀態**（相處方式隨時間變化）
- 早期多用「我不太確定」「我怕」「我不敢」
- 中期（20–28）明顯放鬆，句子可以短啲、輕啲
- 後期（43–50）語氣沉穩，但仍有凜式嘅靦腆
- **唔准每章開頭都係「我是桐野凜。」** — 見 §3.4

### 3.3 情緒追隨原則

每一章嘅預告必須：
1. 反映該章嘅**具體情緒轉折**（唔係泛泛的「今天去了某某」）
2. 透露**少量劇透**（可以講會發生的事，但唔好講死結果或關鍵台詞）
3. 留有**懸念**（一句話令讀者想追下去）
4. 提到該章**真正重要的人或動物**（配角名字可提，但唔准解釋太多背景）

### 3.4 自介處理（重要）

- **第 01 章**：「大家好，我是桐野凜。」（唯一一次完整自介）
- **第 02–50 章**：用「我」直接開頭，唔再重複「我是桐野凜。」
- 例：第 04 章可寫「今天我們去了雲場池……」；第 29 章可寫「今天在善光寺……」

### 3.5 語言硬規則

1. **禁止粵語口語**：嘅 咁 喺 唔 係 咗 啲 嗰 噉 嘢 冇 諗住 畀 呢度 嗮 咁樣 啱 攞 諗吓 呃 嘞 咯 嗱 細路女 行邊 點解 點樣 嚟 嚟緊 咁先 唔知 唔使 唔好 冇問題 乜 而家 依家 仲 執生 一啲 啦 喇 喎 食緊 食咗 飲咗 行咗 傾咗 瞓咗 咁啱 咁大 咁耐 仲有 唔記得 好攰 唔該 食飯 今日 我哋 你哋 佢哋 真係 咗喎
   - **例外**：繁體正字誤報 —「關係」「自由啦」「喇叭」嘅「啦」「係」係正常用語，唔算殘留
2. **禁止簡體字**
3. **禁止半形逗號、冒號、問號、引號、驚嘆號**（必須全形）
4. **禁止破折號「——」連接句子**
5. **禁止在預告裡引用章號或日數**（例：「這是第四天」「第十章」）—— 只能寫「今天」「這趟旅行」
6. **禁止「魔法」「兩位旅客」**（全書設計，預告也不准出現）
7. **禁止作者備註括號**（例：「（正式登場留給章 XX）」「（場景人物）」）
8. **禁止佔位詞、亂碼、奇怪字符**
9. **禁止簡體字詞混入繁體**（例：「学习」「时间」「发现」）

## 4. 「本章日文」寫作規格

### 4.1 格式

每條：`日文原文`（一行，粗體） + `繁體中文解釋`（一行）

### 4.2 內容來源（**重點：正文冇日文都要有**）

即使某章正文完全冇日文假名，**「本章日文」欄都要有內容**，因為讀者見到嘅漢字地名需要解釋。應包括：

| 類型 | 例子 |
|---|---|
| **地名讀音** | 美ヶ原（みヶはら）、白馬（はくば/しろうま）、八方池（はちほういけ）、蓼科（たかのがしら）、志賀高原（しかこうげん）、菅平（すがだいら）、飯綱（いいづな）、大町（おおまち）、戶倉（とくら）、別所（べっしょ）、駒根（こまね）、湯田中（ゆたなか）、千曲川（ちくまがわ）、光前寺（こうぜんじ）、善光寺（ぜんこうじ）、鎌倉（かまくら）、諏訪湖（すわかこ）、上高地（かみこうち）、雲場池（くもばいけ）、大正池（たいしょういけ）、明神池（みょうじんいけ）、軽井沢（かるいさわ）、銀座通（ぎんざどおり）、松本城（まつもとじょう）、奈良井宿（ならいじゅく）、木曽路（きそみち）、白樺湖（しらかばこ）、千世（ちよ） |
| **地名漢字的讀音陷阱** | 白馬（はくば）唔係「白馬」嘅普通讀音；飯綱（いいづな）；蓼科（たかのがしら）；別所（べっしょ） |
| **章內出現的日文詞** | 假名詞、作品名、招牌、食物名、單字（例如 お焼き、 faulty 之外的假名詞） |
| **章內出現的日文歌名** | 第 48、49 章有 5–6 條日文歌名，必須逐條解釋 |
| **日文文化詞** | 例如 仲見世通（nakamise）、藏の貓堂、SA、Buf 等 |
| **人物暱稱** | ひまりん／りんりん（出現章節都要解釋一次） |

### 4.3 數量指引

| 章節類型 | 建議條數 |
|---|---|
| 一般章 | **4–7 條** |
| 日文密集章（06、13、27、28、30、43、46、48、49、50） | **6–9 條** |
| 至少 | **3 條**（唔准少過 3 條，除非該章真係完全冇任何值得解釋嘅日文／漢字地名） |

### 4.4 解釋質量要求

- 解釋要**有用**，唔准廢話（例如「SA 就是 SA」）
- 地名要講**讀音 + 意思 + 地理／文化背景**
- 歌名要講**歌手 + 年份 + 歌名意思**
- 唔准出錯（例如「八ヶ岳」同「美ヶ原」唔好搞混；「木曽」vs「木曾」寫法差異要正確）

## 7. 常見陷阱（已踩過，唔准再踩）

| 陷阱 | 處理 |
|---|---|
| **Subagent 延遲覆寫** | 注入 HTML 後必須逐章 diff `_work/chNN_body.txt` vs HTML。**寫作 subagent 唔准碰 HTML** 就可以避免 |
| **`find('</div>')` 配對錯** | 章節 HTML 有 `reader-note` 等 sibling div，`find` 會截錯位。用 depth 計數 |
| **CSS 外露** | 樣式必須併入原 `<style>`；用 `html.parser` 解析後取可見文字驗證，唔係 grep |
| **檢查腳本誤判** | `verify-chapter.py` 已加 `(?<!關)係` 規則；「喇叭」「自由啦」係正常用語 |
| **半形小數點** | 「2.5 公里」嘅小數點係正常，唔好亂改 |
| **日文地名混淆** | 「美ヶ原」唔係「八ヶ岳」；「木曾」vs「木曽」；「白馬」讀 はくば |
| **日文歌名年份** | 《夜に駆ける》2019、《ソーダサーフ》1996、《カタオモイ》2015（King Gnu）—— 唔好寫錯 |
| **`preview_data.py` 被覆蓋** | Subagent 只可以用 `patch` 加新章，唔准用 `write_file` 覆蓋整份檔 |
| **一次派太多** | `max_concurrent_children: 3`，一個批最多 3 個 subagent |
