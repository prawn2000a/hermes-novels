## 網文寫作解剖學

由一部 2,757 章商業網文的全書實測拆解而來，把可重用的寫作規格、結構與模板整理成 16 頁：

- **十二章** — 核心公式、機制層、劇情層、節奏層、開篇、反套路、心聲與震場、對話與稱謂、標點排版、章尾鉤子、檢查流程、失敗模式
- **四個附錄** — 技法庫、寫作模板、實測數據、自動檢查器

頁面路徑與檔名全部使用英文（GitHub Pages 對中文路徑會回傳 404）。

### 內容來源說明

所有數據來自一部商業連載網文的實測（2,757 章、6,766,156 字）。書名、人物名、機構名、地名與具體情節序列一律未收錄；原書專有名詞已全部中性化為描述。連續 12 字以上中文片段抄錄數 **0**，引號內容抄錄數 **0**。
