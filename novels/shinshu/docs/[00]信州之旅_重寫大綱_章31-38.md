## 批次 4：章 31–38（Bad Guys Close In → All Is Lost）

### 整體弧線設計

這 8 章是全書「危機逼近」段。核心是**外部危機（天氣、海拔、迷路）與內部危機（凜的「維持現在」策略）交疊**，最後在章 37 第一次攤牌失敗。

**章 29 地震之後，關係實際上已經越線了**（十五秒擁抱、凜的坦白「如果我不在了」）。但兩人都沒有說出口。章 31–38 的難題是：**關係已經改變，但兩人仍在用「不定義」保護它。**

到了章 36（蓼科暴雨迷路），凜在霧中承諾「不想旅程結束」——但她的保護方式（維持現在、維持不定義）反而逼走陽葵。章 37 是第一次真正的攤牌失敗。

### 章 31 ｜ 飯綱早晨・鳳凰盒 + 早期離開

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In |
| **起點 → 終點** | 飯綱高原旅館 → 飯綱天鵝湖（清晨）→ 國道 18 號 → 菅平高原 |
| **時段** | 清晨 → 深夜 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 飯綱天鵝湖（清晨版，**刻意避開章 30 的黃昏場景**）、菅平高原入口 |
| **配角** | 飯綱民宿老闆娘（**不命名**，泛稱） |
| **核心物件** | 鳳凰盒（**放在儀表板前方，木面朝上，沒有任何光**）＋御朱印帳 |

**情節節點**

1. 清晨五點，凜醒來。地震的記憶被睡眠沖淡，只剩手機上的一則通知。
2. 早餐前，凜把鳳凰盒從背包拿出來放在桌上，**確認裡面的御朱印帳在**。她打開盒蓋看了一眼，裡面只有一張紙。她把盒蓋闔上。
3. **清晨的天鵝湖**（刻意與章 30 區隔）：
   - 天還沒全亮，湖面有薄霧。
   - 白天鵝在霧裡游，動作比昨天更慢。
   - 陽葵把手伸進水裡，說：「水是暖的。」——**這是陽葵第一次主動碰水**。
4. **早期離開**：八點退房，比預定的行程早。凜在筆記本寫下「提早離開」三個字，然後劃掉，改寫成「提早出發」。
5. 國道 18 號往北。陽葵問「為什麼提早？」凜答「因為我想看菅平的雲」。**這是凜第一次為了看東西而主動改變行程**（與章 23 的第二次改道呼應，但這次是主動的）。
6. 經過一個長上坡，海拔從 1000 升到 1200 公尺。氣溫降了。陽葵開暖氣。
7. 午後抵達菅平高原。**章末鉤子**：凜在筆記本寫「飯綱。菅平。鳳凰盒裡還只有一張紙。」然後她停筆很久——因為她意識到，**盒子是空的這件事本身就是她最在意的事**。

**情緒弧**：平靜（清晨）→ 微妙的不安（確認盒子裡的東西）→ 第一次主動改變（提早出發）→ 意識到「空」

**要刪除的舊稿特徵**：
- ❌ 重複章 30 的天鵝湖黃昏場景（**本章只寫清晨，且天鵝在霧裡**）
- ❌ 「飯綱的 魔法」
- ❌ 章號式標題開頭

**章末鉤子**：凜在筆記本寫「飯綱。菅平。鳳凰盒裡還只有一張紙。」

### 章 32 ｜ 飯綱→菅平高原

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In |
| **起點 → 終點** | 菅平高原旅館 → 菅平牧場・滑雪場舊址 → 同一間旅館 |
| **時段** | 清晨 → 深夜 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 菅平高原（海拔 1200 公尺）、舊滑雪場遺址（1950 年代）、菅平神社 |
| **配角** | 菅平旅館老闆（**不命名**，泛稱） |
| **核心物件** | 凜的摺疊地圖（**本章攤開在地圖上用筆畫路**）＋陽葵的公路歌單 USB |

**情節節點**

1. 清晨，凜把摺疊地圖攤在旅館的矮几上，用鉛筆畫出今天的路線。她畫得很細，每一個轉彎都標了數字。
2. 早餐後出發。**陽葵的手機壞了**（螢幕摔裂，導航不能用），所以凜的地圖成了唯一的導航依據。**這是凜第一次真正被需要。**
3. 舊滑雪場遺址：荒蕪的纜車塔、堆積的雪具殘骸、1960 年代的木屋。
   - 陽葵在殘骸裡撿到一枚生鏽的吊牌，說要帶回去。
4. **菅平神社**：小小的石階，長滿青苔。陽葵在這裡第一次主動對凜說出「我媽媽其實很擔心我」。
5. **凜的判斷錯誤（本章核心）**：凜在地圖上畫了一條近路，可以省 40 分鐘。她很有把握。
   - 走到一半，發現是死路（崩塌或施工封路）。回頭多花了一個半小時。
   - **凜沒有道歉，也沒有自責**。她只是默默地把地圖收起來。這是她的退步——她開始不說了。
6. 回到旅館時天已經黑了。陽葵沒有抱怨，只是說「明天走大路吧」。
7. **章末鉤子**：凜在筆記本寫「今天我畫錯了一條路。」然後在下面補：「我沒有告訴她。」

**情緒弧**：自信（凜的地圖）→ 順利（舊滑雪場）→ 溫柔（神社）→ 打擊（死路）→ 沉默（凜不說）

**要刪除的舊稿特徵**：
- ❌ 「我的計畫從來沒有錯過」呢類自我確認
- ❌ 「菅平的 魔法」

**章末鉤子**：凜在筆記本寫「今天我畫錯了一條路。」然後在下面補：「我沒有告訴她。」

### 章 33 ｜ 菅平・遇 OL 三人組

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In |
| **起點 → 終點** | 菅平高原旅館 → 志賀高原道路 → 志賀高原溫泉旅館 |
| **時段** | 上午 → 夜晚 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 志賀高原（四國連山方向可見）、志賀高原溫泉 |
| **配角** | **OL 三人組：小春・楓・美月（frozen，當地人）** |
| **核心物件** | 凜的旅行筆記本＋陽葵的公路歌單 USB |

**情節節點**

1. 上午出發，走大路。凜這次主動說「走大路」，陽葵點頭。
2. **停靠點的意外相遇**：三個 OL 在展望台泡飲料。陽葵因為太開朗，先開口搭訖。
   - **小春**（最外向，主導）：問她們是不是在旅行。
   - **楓**（戴眼鏡，安靜）：問「你們是情侶嗎」。**這個問題讓凜整個人僵住。**
   - **美月**（最小，插話）：說「可是你們兩個坐同一邊欸」。
3. **凜的社交障礙場景（本章核心，要寫得細）**：
   - 凜想說話，說不出來。她數了三秒，還是只說了「嗯」。
   - 陽葵替她接話，說得又快又自然。凜反而覺得被搶走。
   - 三人組離開後，凜問陽葵：「她們是不是覺得我們很奇怪。」
   - 陽葵答：「我覺得她們只是想有人講話。」——**這句話刺中凜**（凜從來不主動）。
4. **第二次搭訖（凜主動）**：在展望台的另一邊，凜看見一個空的飲料瓶掉在草地上。她走過去撿起來放進垃圾袋。**這是她能做的、屬於自己的社交。**
5. 午餐（山小屋）。陽葵問：「三個人一起走會不會比較熱鬧。」凜答：「會。」然後停頓，又說：「但我不想只是被帶著走。」
6. 抵達志賀高原溫泉旅館。**章末鉤子**：凜在筆記本寫「今天有三個人跟我們說話。」然後她劃掉「三個人」，改成「我說了兩句話。」

**情緒弧**：熱鬧（三人組）→ 僵住（凜社交障礙）→ 刺痛（被帶著走）→ 小小的自主（撿瓶子）→ 記錄

**要刪除的舊稿特徵**：
- ❌ 「兩位旅客的 魔法」
- ❌ 設定式介紹 OL 三人組（年齡、職業），要靠動作呈現

**章末鉤子**：凜在筆記本寫「今天有三個人跟我們說話。」劃掉「三個人」，改成「我說了兩句話。」

### 章 34 ｜ 菅平→志賀高原

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In |
| **起點 → 終點** | 志賀高原溫泉旅館 → 志賀高原道路 → 志賀高原山莊 |
| **時段** | 清晨 → 深夜 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 志賀高原（海拔 1200 公尺）、志賀高原湖泊群（北攝・ Paul's Pond）、志賀高原山莊 |
| **配角** | 山莊主人（**不命名**，泛稱） |
| **核心物件** | 陽葵的公路歌單 USB＋凜的摺疊地圖 |

**情節節點**

1. 清晨，志賀高原下了一整夜雨。窗外是白的。
2. 上午開車。海霧。**能見度不到 50 公尺**，凜在副駕報路，陽葵開得很慢。
3. **湖泊群**：北攝湖、保鑣湖（Pauls Pond）。水色是深綠，岸邊是沒有葉子的樹。
   - 凜拍了很多照片。陽葵在湖邊石頭上坐了很久。
4. **陽葵的第一次沉默**（本章核心）：陽葵沒有像平常那樣一直說話。她看著湖，說：「我以前覺得，只要一直走就不會錯。」
   - 凜問：「現在呢。」
   - 陽葵答：「現在我不知道走的時候要去哪裡。」——**這是成年禮命題的回聲**。
5. 山莊。木頭地板，晚上很冷。凜在筆記本寫下今天的日期，然後劃掉，因為寫日期讓她想到「還剩多少天」。
6. **凜開始數日子**（伏筆）：她在筆記本最後一頁寫下「還有幾天」，但沒有算出答案。
7. **章末鉤子**：凜半夜醒來，走到窗邊。陽葵也醒著，坐在另一張床上看手機。兩人隔著黑暗對看，誰都沒有說話。

**情緒弧**：濕冷（雨）→ 沉靜（湖）→ 陽葵的第一次坦白 → 凜的焦慮（開始數日子）→ 無言的夜

**要刪除的舊稿特徵**：
- ❌ 「志賀的 魔法」
- ❌ 陽葵一直講不停（本章她必須安靜下來）

**章末鉤子**：凜半夜醒來，看見陽葵也醒著。兩人隔著黑暗對看，誰都沒有說話。

### 章 35 ｜ 志賀・木戶池

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In |
| **起點 → 終點** | 志賀高原山莊 → 木戶池 → 同一個山莊 |
| **時段** | 清晨 → 深夜 |
| **字數目標** | 2000（1800–2400） |
| **必到景點** | 木戶池（志賀高原最大湖泊，海拔 1200 公尺）、湖畔濕原、木棧道 |
| **配角** | 無 frozen 配角（**兩人獨處章**） |
| **核心物件** | 凜的旅行筆記本＋鳳凰盒（**本章凜第一次單獨帶著鳳凰盒走棧道**） |

**情節節點**

1. 清晨，霧。凜一個人先出門去木戶池。**她沒有叫醒陽葵**——這是她第一次主動離開兩人。
2. 木棧道穿過濕原。木板在腳下響。霧把遠山全部藏起來，只剩最近的一棵枯樹。
3. **凜與鳳凰盒的獨處（本章核心）**：走到木棧道盡頭的展望台，凜把鳳凰盒拿出來。
   - 她打開盒蓋。裡面有御朱印帳（**這一張**），還有兩塊泉水石。
   - 她把三樣東西排出來，排在木欄杆上。
   - **她想著還差什麼**——但她不知道答案。她只知道，湊滿不是靠數目。
   - 她寫：「鳳凰盒。御朱印。兩塊泉水石。還差一樣，但我不知道是什麼。」
4. **霧裡的聲音**：有人在下面叫她的名字。是陽葵，氣喘吁吁地跑上棧道。
   - 陽葵說：「我醒來你不見了，我以為……」
   - 她沒有說完。凜說：「對不起，我應該講一聲。」
   - 陽葵說：「下次要講。」——**這是第一次，凜因為自己的行為道歉。**
5. 回程。陽葵走在前面，凜走在後面。霧在散。
6. **章末鉤子**：凜在筆記本寫「木戶池。霧。我一個人離開了一次。」然後在下面補：「陽葵跑上來的時候，我在想，其實我不是想一個人。」

**情緒弧**：孤獨（獨自出門）→ 靜（鳳凰盒三樣東西）→ 驚（陽葵跑來）→ 歉意（第一次道歉）→ 承認

**要刪除的舊稿特徵**：
- ❌ 「木戶池的 魔法」
- ❌ 陽葵生氣指責凜（這裡是溫和的）

**章末鉤子**：凜在筆記本寫「木戶池。霧。我一個人離開了一次。」補：「陽葵跑上來的時候，我在想，其實我不是想一個人。」

### 章 36 ｜ 蓼科暴雨・行山迷路・霧中名場面

| 項目 | 內容 |
|---|---|
| **拍數** | Bad Guys Close In（**第五個天氣轉折點**） |
| **起點 → 終點** | 志賀高原山莊 → 蓼科山莊 → **山裡（迷路）** |
| **時段** | 上午 → 深夜 |
| **字數目標** | 2100（1900–2400） |
| **必到景點** | 蓼科山莊、蓼科晨霧（could be 下午霧）、白樺湖方向步道、**迷路地點** |
| **配角** | 蓼科山莊主人（**不命名**） |
| **核心物件** | 凜的摺疊地圖（**本卷第一次在山中派上用場**）＋手機電量 |

**情節節點**

1. 上午出發前往蓼科。**天氣預報說下午有雨，凜這次選擇相信預報，提前出發**（她的成長）。
2. 蓼科山莊。午餐。下午三點開始下雨，然後越下越大。
3. **凜決定不等雨停**（因為山莊要滿房，兩人必須走）。她們在雨裡走。
4. **山徑**：能見度掉到 10 公尺以下。凜把摺疊地圖攤在雨傘下看，但地圖是紙做的，邊緣已經濕了。
5. **迷路**：分岔路。凜記得是左邊，但左邊有一個警告牌，被雨淋得看不清。
   - 走了一個半小時，發現不對。
   - **回頭找**：雨太大，沒有人走過的痕跡已經被沖掉。
6. **凜的第一次崩潰（本章核心）**：
   - 她坐在濕透的石頭上，說：「是我害的。」
   - 她說：「如果我沒有提早出來，就不會在這裡。」
   - **她的恐懼不是迷路，是「我讓你陷入危險」**。
   - 陽葵在她旁邊坐下來。
7. **霧中名場面（要寫得細，靠身體動作）**：
   - 雨小下來。霧從山谷升起來。
   - 陽葵把手伸過來，握住凜的手。凜的手很冷。
   - 陽葵說：「我可以生氣。我其實很生氣。」
   - 凜問：「為什麼還在這裡。」
   - 陽葵說：「因為我想你在。」
